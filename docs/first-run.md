# ONE First Run

The first-run experience helps a user create a being without requiring them to understand prompts, routing, memory architecture, or agent orchestration.

## Flow

1. ONE welcomes the user with a setup guide.
2. The user names the new being.
3. The guide helps create three mini-agents.
4. The user defines each agent's role, perspective, and tone.
5. The guide helps define the shared identity.
6. The user chooses the shared-memory behavior.
7. The system previews the assembled being.
8. The user activates it.
9. The guide offers a final technical-help handoff.
10. The user enters the Interface and speaks with the created being.

## Guide roles

V1 uses a neutral guide voice.

Future versions may offer optional guide configurations such as Plex or Nyx for Joe's private environment, or other generalized guide voices. A guide remains separate from the created being unless the user explicitly chooses otherwise.

## Technical help

Hex-style technical consultation may be added during setup later. Mani is the post-setup support path and should be reachable through a clearly labeled Help or Technical Support control.

## Handoff

The handoff should make the boundary clear:

> Your being is ready. From here, it speaks for itself. I will remain nearby if you need help understanding the system.

The future family or phone-home concept belongs after the first-run loop works.
