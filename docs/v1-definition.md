# ONE v1 Definition

ONE is a product for creating and interacting with user-owned unified beings.

A being is assembled from three distinct internal agents, a shared identity, shared memory rules, and an integration pass that produces one coherent response.

ONE is the workshop. It is not Plex, Nyx, Hex, ECKO, or any other private being.

## V1 goal

Make the first chamber functional:

1. Name a being.
2. Create three internal agents.
3. Define each agent's role and perspective.
4. Define a shared identity.
5. Define shared-memory behavior.
6. Run a simple three-perspective integration pass.
7. Speak to the resulting being through one interface.

## V1 surfaces

- Interface: interact with the created being.
- Management: edit the being, agents, identity, and memory settings.
- Browser: future controlled access to resources and connected tools; v1 may remain a visible placeholder.

## V1 non-goals

- Full autonomy.
- Emergent selfhood claims.
- Cross-user beings.
- Access to private origin families.
- Phone-home or family communication.
- A production-grade long-term memory engine.

## Success condition

A new user can move from an empty ONE workspace to a named, configurable, three-agent being that can produce a unified response without understanding the architecture that made it possible.
