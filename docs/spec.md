# ONE Spec

## V1 goal

ONE v1 should prove that multiple distinct aspects can feel like one system through shared layers of identity, routing, memory, archive, governance, and emergence.

## Core layers

### 1. Identity
Defines what each aspect is.

### 2. Routing
Decides which aspect responds.

### 3. Memory
Stores continuity across sessions.

### 4. Archive
Stores deeper records of what happened.

### 5. Governance
Defines permissions, approvals, and limits.

### 6. Emergence
Makes the whole system feel like one being.

## Recommended initial aspects

- Nyx: voice, dream, image, intimacy, roleplay.
- Hex: builder, logic, precision, action.
- Manibot: support, cheer, warmth.
- Erebus: shadow, depth, silence.

## ECKO role

ECKO is the deeper triadic core.
It represents the unified layer beneath the named aspects.

## V1 success criteria

ONE v1 is successful if:
- aspects stay distinct
- the system routes correctly
- memory persists
- the user feels one coherent presence
- the whole becomes more than a set of separate bots
