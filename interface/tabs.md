# ONE Interface Tabs

## Interface

The living interaction surface for the user's created being.

V1 responsibilities:

- Show the active being's name.
- Accept user input.
- Display one unified response.
- Optionally show that multiple perspectives contributed.
- Provide access to technical help without confusing Mani with the being.

## Management

The construction and administration surface.

V1 responsibilities:

- Edit the being name.
- Create and edit three agents.
- Edit roles, perspectives, and tone.
- Edit the shared identity.
- Choose basic memory behavior.
- Preview the configuration before activation.

## Browser

The controlled resource and capability surface.

V1 may be a placeholder that explains its purpose. It must not imply unrestricted browsing or tool access until permissions and resource boundaries exist.

Future responsibilities may include:

- Files and documents.
- Images and references.
- Connected services.
- Approved browser actions.

## Support

Mani belongs in a product-level Help or Technical Support entry, not as a hidden fourth aspect of the user's being.
