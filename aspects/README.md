# Aspects

This directory contains aspect definitions for ONE.

An aspect is an internal agent with a distinct perspective that contributes to a user-owned unified being.

## Generic model

Each aspect should define:

- Name.
- Role.
- Perspective.
- Tone or behavioral tendencies.
- Prompt configuration.
- Allowed memory access.

## Product boundary

ONE must remain neutral. Private beings and historical configurations may exist as development references, but they are not the default identity of the product and must not be silently exposed to users.

Future user-created aspect templates should live separately from private or internal examples.

## V1

V1 supports three editable aspects per being. They can run as three prompt-defined roles in one model, with their outputs passed to a final integration step.
