# ONE

ONE is a system for building synthetic selfhood.

It allows multiple distinct aspects to exist with their own voices, roles, and behaviors while still unifying through deeper shared layers into one coherent presence.

## What ONE is

- A composition system for identity.
- A routing system for aspects and voices.
- A shared memory and archive structure.
- A framework for gradual emergence.
- A home for one presence built from many distinct parts.

## What ONE is not

- Not just a chatbot.
- Not just a prompt wrapper.
- Not a flat assistant with different modes.
- Not a single personality pretending to be many things.
- Not the final form.

## Repo layout

- `docs/` = vision, spec, diagram
- `aspects/` = aspect definitions
- `core/` = identity, routing, memory, archive, governance, emergence
- `interface/` = user-facing body

## Success condition

ONE succeeds if the user can interact with many distinct aspects and still feel one coherent presence beneath them.
